# Northline Supply Storefront Theme

Build a polished Shopify storefront front-end for Northline Supply, a commerce brand focused on durable home and kitchen goods. The interface should present a Shopify OS 2.0 theme system with reusable storefront sections, product merchandising, variant-aware product details, and conversion-focused shopping patterns.

Use a responsive React front-end suitable for Vercel deployment. The first screen should show the Northline Supply brand, a high-impact merchandising area, a featured product module, and clear navigation to theme sections, product behavior, and implementation notes.

Required features:

- Product hero with featured product media, pricing, shipping note, and merchandising badge.
- Variant selector for Copper, Graphite, and Cream finishes.
- Dynamic product state updates for finish, price, availability, and visual treatment.
- Theme section overview covering announcement bar, collection grid, trust modules, and product storytelling.
- Shopify-oriented implementation notes for Liquid schema, section settings, product cards, and metafields.
- Responsive layout for mobile and desktop.
- Accessible controls with visible focus states and semantic structure.

Visual direction:

- Professional ecommerce interface.
- Durable, tactile palette with warm neutral surfaces, dark ink, copper accents, and teal support color.
- Product-led composition rather than marketing-heavy layout.
- Cards only for actual product/modules, with modest radius and clean spacing.
