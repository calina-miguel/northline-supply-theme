# Northline Supply Storefront Theme

Custom Shopify OS 2.0 storefront work for Northline Supply, covering reusable sections, product-template behavior, schema-style settings, responsive merchandising, and variant-aware UI.

Production: https://northline-supply-theme.vercel.app

## Scope

- Theme-editor friendly section architecture
- Liquid schema awareness
- Product-card and variant-state logic
- Responsive storefront layout
- Conversion-focused merchandising blocks

## Stack

- HTML, CSS, JavaScript
- Vercel hosting

## Local Operations

```bash
npm run start
```

The application is served as a static storefront interface and can be deployed directly through Vercel.
